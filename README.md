Simple Calculator Web App

This is a basic calculator web application built using HTML, CSS, and JavaScript. It provides a clean and minimal user interface for performing standard arithmetic operations directly in the browser.

Check the Preview: 

🚀 Features
Perform basic calculations: addition, subtraction, multiplication, and division
Percentage (%) operation support
Clear (Cl) button to reset the screen
Delete (DEL) button to remove the last digit
Responsive and centered layout
Interactive button effects with hover and click animations

🛠️ Technologies Used
HTML – Structure of the calculator
CSS – Styling and layout design
JavaScript – Functionality and logic handling

⚙️ How It Works
User inputs numbers and operators using buttons
The input is displayed on the screen dynamically
The eval() function is used to calculate the result when the = button is pressed
Additional functions handle clearing input and deleting characters

📂 Project Structure
Single HTML file containing:
Inline CSS for styling
Inline JavaScript for logic
